How to use the scanner & understand your results

1. Take a clear photo

Use even light, avoid glare, and keep every card fully visible. You can photograph a binder page or loose cards. This beta supports Magic: The Gathering only.

2. Scan and review

Choose Identify my cards and allow a few minutes. One submitted photo uses one scan credit, even if identification fails. Reconnecting to the same scan does not use another credit. If you run out, ask Douglas for more scans. To use the access request form, sign out first.

Check the card name, set and collector number before relying on a result. Green circles mean the card was placed; yellow means review it; red means it was not identified reliably.

3. Read the photo and prices

Prices are shown as nonfoil, then foil. They are daily Cardmarket reference prices via Scryfall, not live offers. The scanner does not determine whether your physical card is foil.

With collection checking enabled, pink panels mark an exact printing you still need; amber means ownership could not be determined. The gold trophy highlights the highest-value printing you still need, using the foil price only when no nonfoil price is available. Double-faced cards use a two-copy target.

4. Save cards to your collection

Add identified cards to collection saves one copy of each identified card with a set and collector number. The same scan can only be added once; scanning those cards again adds more copies. Different sets, collector numbers and languages stay separate.

Turn on Automatically save identified cards before scanning to skip the manual save step. It is off by default and remembered for this browser tab. Leave it off if you want to review first. Saving continues even if you close the page; a failed save can be retried manually.

5. Check what you own and download your cards

To track your existing collection, you need an MTG Studio database containing your cards. Open that database in the Enfolderer desktop client, choose Scan → Export Mobile Collection Snapshot, then upload the exported JSON file in Track an existing MTG Studio collection below. Do not upload the database itself. Export and upload again when your collection changes.

Check my collection compares against saved scanned cards and any optional desktop collection file. If the same copies appear in both, they are counted twice. Ownership totals combine languages. A scan does not count its own newly saved cards, and saving later does not change an existing result photo.

No MTG Studio database? You can still save newly scanned cards and check against those saved cards. They are stored separately and do not update an MTG Studio database.

View scanned collection lets you filter by set and download saved quantities as CSV. The scan-result CSV is a separate price-ranked report, not a desktop import file. Downloads and collection browsing do not use scan credits.
